# 分阶段发展规划

每完成一个阶段停止，汇报验收结果和下一阶段计划，等待用户指示。阶段之间不自动继续，也不自动发布。

## 第一阶段：可靠性验证与失败恢复

目标：每个公开输出格式都有真实成功样例，失败后页面可恢复，依赖来源和处理边界可核查。

- 固定并更新常用依赖，本地分发脚本和许可证，检查 SHA-256。
- 修正 WASM URL、PDF.js 模块路径和新版资源释放 API。
- 依赖单次加载、超时、失败重试；音视频任务超时和引擎释放。
- 真实 Chrome 文件转换测试，直接使用正式 dist 发布文件。
- 独立静态构建目录、GitHub Actions 验证配置、公开隐私与支持范围说明。

验收记录在 [STAGE-1.md](STAGE-1.md)。

## 第二阶段：批量处理与结果管理（已完成本地验收）

范围：图片批量转换、拖拽上传、尺寸调整、前后体积对比、任务结果保留、统一 ZIP 下载。增加 PDF 选页和图片排序。

验收：一次处理多文件，单个失败不丢失其他结果；切换功能后仍可下载；批量输出的数量、格式、尺寸与用户选择一致。

验收记录在 [STAGE-2.md](STAGE-2.md)，后续已按用户指示推送并完成 [线上验收与修复](LIVE-VERIFICATION.md)。等待用户指示开始下一阶段。

## 第三阶段：资源控制与输出质量（已发布）

范围：统一任务队列、用户取消、进度反馈、内存预算，改善文档分页和内容丢失提示。

验收：长任务可取消，之后能启动新任务；超限提前拒绝；转换保留范围和丢失信息清晰可见。

3A 已实现共用任务生命周期、取消与进度、结果及主要操作的估算预算、文档分页与逐结果说明，已推送 `533d535`。3B/3C 已推送 `cbe0c53`，GitHub CI 与 Cloudflare Pages 均成功，新版线上队列 6 项验收通过。记录见 [STAGE-3.md](STAGE-3.md)。真实用户文档及实体手机仍待补充；首次 FFmpeg CDN 下载不稳定仍是已知边界。

## 第四阶段：分发与选择性离线（本地验收完成，发布验收中）

范围：独立功能入口、按功能缓存依赖、PWA 与离线状态、示例文件和使用指南。

验收：明确已缓存功能可在断网时使用；首次加载和缓存更新行为可解释；不误报尚未缓存的功能为离线可用。

已实现按功能手动缓存、SHA-256 校验、音视频核心持久缓存、PWA 清单、片段功能入口、示例和使用指南。版本更新等待旧页面关闭；缓存检查与清理明确区分程序资源和文件结果。发布前补充跨标签页状态同步、图片 ZIP 断网验收、音视频失败重试和发布目录检查；本机真实 CDN 首次准备后断网音频转换通过。验收记录见 [STAGE-4.md](STAGE-4.md)。完成本阶段后停止，不自动推送。

下一步按用户指示发布，再验证 Cloudflare 线上离线准备与更新、浏览器安装行为和实体手机离线恢复；真实 CDN 可达性仍需在发布后复核，再根据真实文件反馈决定后续改进。
