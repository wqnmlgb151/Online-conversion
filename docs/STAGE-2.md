# 第二阶段验收记录

日期：2026-10-07。状态：本地验收完成；已按用户指示开始推送与线上验收，线上结果另行记录。

## 已完成

- 图片批量转换，每批最多 100 个文件，逐个解码和释放画布；单个损坏文件单独记录失败，其他文件继续处理。
- 图片与 PDF 输入区支持拖拽，展示已选择文件；沿用单文件和总大小检查。
- 图片支持指定宽高、单边缩放、保持比例适配范围和指定尺寸拉伸；显示前后尺寸、体积及增减比例。调整后的最大边长为 8192 像素，总像素最多 4000 万。
- 各功能成功输出保留在统一结果区；切换功能、重新选文件和之后的转换失败不会清除已有结果。
- 单项下载、删除、清空和全部成功结果 ZIP 下载；同名文件以编号区分，失败记录不加入 ZIP。
- 删除和清空结果释放对应 Blob URL；新增或删除结果也释放过时的 ZIP 下载副本；离开页面时清理结果。
- PDF 文本及图片导出支持单页、范围和组合选页，按填写顺序输出并去重；超过 50 页的 PDF 可选取最多 50 页导出图片。
- 图片合并 PDF 支持上移和下移，实际 PDF 页面按调整后的顺序输出。
- 更新使用说明、隐私说明和线上地址：https://online-conversion.pages.dev/（由用户提供，Cloudflare Pages 同步 GitHub）。

## 范围与限制

结果保留在当前页面内存中，刷新或离开页面后不恢复；下载到本机的文件不受清空影响。ZIP 包含所有成功结果，包括各功能生成的 ZIP 文件，不会展开已有 ZIP。批量失败后点击重试会重新执行整批，成功结果会继续保留。

测试使用 Windows Chrome 和合成样本，不能代表所有复杂图片、Office 排版、大文件或移动设备。手机宽度验收是在桌面 Chrome 调整视口；音视频回归仍使用经过校验的核心缓存。此次完成的是本地 dist 验收，尚未对线上第二阶段版本进行验证。

当前仍通过全局忙碌状态阻止并发转换；保留大量结果会增加内存占用。任务取消、完整进度和统一内存预算属于第三阶段。
