# 第三阶段 3A：任务控制与资源保护

日期：2026-10-09。3A 已推送至 `main`，提交 `533d535`，GitHub verify 与 Cloudflare Pages 均成功。3B/3C 完成本地验收，用户已授权最终检查后发布；实际发布结果以 Git 提交与部署检查为准。

## 已实现

- 共用任务取消状态；保持执行锁直到清理完成，取消后的异步结果不会写入结果区。
- 图片和 PDF 批次检查点、按文件/页数进度；FFmpeg 引擎进度及终止，核心下载支持取消；PDF 渲染可中止，ZIP 生成检查取消状态。
- 取消保留此前成功的结果，允许下一次操作重新开始。
- 结果累计 128 MB 限制并显示占用；画布、文档截图、PDF 图片 ZIP、图片合并、媒体和结果打包估算 256 MB 工作预算。
- 文档 PDF 页尾寻找空白扫描行，避免常见文字行被硬切；画布错误及取消路径释放资源。
- 每个文档结果显示格式损失说明、DOCX 解析警告。
- 纯静态构建、按需依赖、本地处理和现有功能格式保持不变。

## 已知边界与下一步

当前是单任务互斥及批内串行，尚未提供跨功能队列；后续 3B 才加入排队、输入选项快照与任务列表。同步 Office 解析和 html2canvas 截图不能即时响应取消，资源清理前不允许开始新任务。

以上为 3A 当时的边界；队列部分已由下述 3B 实现。

预算是估算，不是浏览器内存硬上限。源图片仍在解码后获取尺寸，Office 压缩包展开及 WASM 内存也不能完全预判。分页空白检测不能保证复杂表格不断行。真实大文件和移动设备压力测试仍待补充，不宣称第三阶段所有目标已完成。

## 3B：跨功能队列与输入快照

- 图片、音视频、文档、PDF、结果 ZIP 串行执行。运行时可切换功能和编辑表单，每次提交冻结文件列表、选项及 PDF 顺序。
- 队列展示运行、等待、完成、失败、取消状态，失败原因保留在对应任务记录。单个失败不阻塞后续任务。
- 单独移除等待任务、清空等待任务；取消当前任务后等待清理，再运行下一项。全部停止需清空等待后取消当前项。
- 最多等待 8 项，运行及等待输入合计 200 MB；完成与移除后释放任务闭包，历史只留最近 20 条元数据。页面离开时清除等待队列并取消当前任务。
- 重试按钮明确使用表单当前选择，避免误以为重放已经释放的旧输入。

验证：24 项单元测试；第一轮 56 项 Chrome 端到端全量通过。ZIP 纳入同一队列后，16 项针对性回归全部通过，包含跨功能文件/尺寸快照、PDF 页码快照、取消与移除、失败后继续、队列上限、ZIP 执行互斥、1200 万像素图片缩放和 390px 手机视口。静态构建与依赖校验通过。

手机视口验证不等同于实体手机内存压力测试；合成纯色大图不代表全部真实照片或复杂 Office 文件。本轮停在 3B，后续优先补真实复杂样本与移动设备验收，再考虑第四阶段。

## 3C：压力验证与资源预算修复

新增 `npm run test:pressure`，全部样本由测试生成，不读取或上传用户的私人文件：

- 10000 行、8 列 XLSX，检查中文、引号、换行、公式缓存值和首工作表边界。
- 80 段 DOCX，包含粗体、表格和外部超链接，检查文字与表格保留、链接过滤、无外部请求及 PDF 多页输出。
- 1000 页 PDF 按指定顺序提取 3 页；超大页面在画布分配前拒绝，随后正常文件仍可处理。
- 1200 万像素纹理图片，在 390px 触控模拟、2 倍像素比及 4 倍 CPU 降速下缩放。
- 连续 22 轮转换/清空后 Blob URL 计数归零，任务历史上限为 20；重复 ZIP 打包前释放旧归档。

发现并修复：保留的 ZIP 没有计入后续工作预算；现记录归档字节数并计入预算，清空或失效时释放额度。重打包先释放旧归档，避免峰值重叠。

修复测试基础设施：本地测试原输出根目录会清除正在运行的线上测试子目录，导致 trace 丢失。两套产物现分别保存在 `test-results/local`、`test-results/live` 和对应报告目录。线上转换已经结束并返回失败时，测试立即报告错误，不再无意义等待成功文字。

最终本地验收：**25 项单元测试、65 项 Chrome 端到端测试全部通过**；语法、依赖文件/许可证校验与 28 个静态文件构建通过。

线上复查：首页恢复 HTTP 200，图片/Office/PDF 等 14 项用例通过。真实 CDN 音视频用例独立复验仍报 FFmpeg 资源下载超时；本地校验缓存的全部音视频格式通过，不能将本地成功等同于真实 CDN 可用。

设备边界：`adb devices -l` 没有列出已连接设备，因此没有实体手机验收。模拟触控与 CPU 降速不代表手机实际内存、温控或浏览器差异；URL 引用归零也不代表测量到了全部 JS/WASM 堆内存回收。真实用户复杂样本仍需额外验证。
