# 第四阶段：分发与选择性离线

日期：2026-10-10（Asia/Shanghai）。本地验收完成，进入 GitHub / Cloudflare 发布与线上验收；发布结果将在下方记录。

## 功能范围

- 页面基础资源自动缓存；图片与 ZIP、文档、PDF、音视频按组手动准备，每组包含结果 ZIP 所需依赖。
- 构建为每项资源生成 SHA-256 校验值及内容版本；包括原本固定校验的 FFmpeg 核心。只有全部依赖存在时才显示可离线。
- 下载超时、校验失败、存储失败不标记完成，已验证的部分可在重试时复用。
- 断网重新打开已准备的站点，可完成图片、文档、PDF，以及准备过核心的音视频转换。
- 查看缓存状态、清除功能缓存；当前转换运行时禁用清理。跨标签页的缓存写入与清理串行执行，准备、失败和清理后通知所有已打开的转换页面刷新状态。
- 新版 Service Worker 不强制接管旧页面；旧窗口全部关闭后激活新版并移除本应用旧版本缓存。其他应用缓存不受影响。
- PWA 清单、主题色、现有 SVG 图标；支持 `#image`、`#doc`、`#pdf`、`#audio`、`#video` 直接入口。功能入口仍共用同一静态页面。
- 提供离线可访问的使用指南和公开 Markdown 示例。
- 构建完成后核查实际发布目录，拒绝多余文件、符号链接和超过 Cloudflare Pages 限制的单个文件；复核资源 SHA-256、版本及 PWA 范围。

## 本地验证

- 29 项单元测试通过，包含缓存不完整/篡改与重试、存储空间失败、准备后排队清理、版本清理的应用范围、忽略上传请求、断网页面缓存返回。
- 73 项 Chrome 端到端全量通过，包含原有转换、批量、队列、取消、压力场景及本阶段离线功能。
- 8 项离线专项通过：断网刷新与功能入口、文档和 PDF Worker、缓存失败恢复/清理、FFmpeg 下载失败复用部分缓存并重试后离线音频解码、PNG/JPG/WebP 及 ZIP 真实下载和解码、离线示例下载、跨标签页准备/排队清理/状态同步、版本等待及旧缓存清理、当前运行任务与清理互斥。
- 发布检查的 4 项异常注入通过：额外文件、资源篡改、版本不匹配、超过 25 MiB 的单文件均被拒绝；测试后恢复原始发布文件。
- 语法、20 项依赖文件/许可证、34 个静态发布资源构建通过。

普通网络失败注入用例禁用 Service Worker，使网络拦截可控；离线用例明确启用真实 Service Worker。常规音视频测试首次下载由固定校验缓存响应 CDN，后续实际切断网络并重新打开页面，使回归测试不依赖当时的公网状态。

本轮另行验证真实 CDN：`npm run media:probe` 未读取测试缓存，完整下载 JS（114,673 字节）与 WASM（32,129,114 字节），SHA-256 与公开 CORS 均通过。独立 Chrome 冒烟无网络响应替换，从真实 CDN 完成首次离线准备，然后切断网络、重新打开页面、将 WAV 转成 MP3 并重新解码，通过。只代表 2026-10-10 本机当次网络情况；此项为本地发布目录验收，线上结果另行记录。

新增可复用的 `npm run test:offline-live`：4 项真实网络验收覆盖图片 ZIP / 使用指南、文档与 PDF Worker、CDN 音频核心、跨标签页缓存状态。在本地发布目录先行运行，4 项全部通过。该专项不替换网络响应，网络或校验失败会明确失败；常规线上网络故障注入禁用 Service Worker，以保持拦截有效。

## 数据与使用边界

离线缓存仅包含程序资源，不包括输入文件、转换结果、任务队列。用户文件仍在当前页面内存中处理，关闭或刷新后不恢复。清除功能缓存保留页面基础资源；彻底移除需要浏览器清理本站数据。功能缓存跨标签页共用，当前页面转换时禁用清理，其他窗口中的转换仍需由用户先完成。

首次访问需要网络；浏览器可能回收 Cache Storage，无痕模式或存储不足也会影响准备。联网标识来自浏览器，不能证明 CDN 可达。更新后重新准备功能，避免缓存代码跨版本混用。

离线功能要求 HTTPS 或 localhost，以及构建生成的 `offline-assets.js`；直接运行源码不包含该清单。尚未验证实体手机 PWA 安装、移动端存储回收，以及本阶段发布后的 Cloudflare 线上更新行为。初次下载失败仍需恢复网络后重试。
