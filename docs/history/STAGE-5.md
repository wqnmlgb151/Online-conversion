# 第五阶段：跟随系统的主题与可读性

> 历史验收／排查记录，结论仅代表文中日期与版本。当前状态见[发展规划](../ROADMAP.md)，临时产物的保留与重建见[维护说明](../MAINTENANCE.md)。

日期：2026-10-12（Asia/Shanghai）。本阶段保持纯静态、本地文件转换的产品范围。

## 改动

- 默认浅色主题；通过 CSS `prefers-color-scheme` 跟随系统或浏览器偏好切换深色，已打开页面实时生效，不依赖新增脚本、依赖或存储。
- 转换首页、使用指南、隐私说明共用颜色变量；适配背景、卡片、文件选择、输入与下拉框、任务队列、离线区域、下载结果、错误提示和键盘焦点。
- 补充 `color-scheme`，使原生控件跟随主题；为两种主题声明匹配的浏览器主题颜色。
- 增强浅色辅助文字、占位文字、输入边框与焦点的辨识度。移除拖拽区背景颜色的过渡，防止系统主题切换时文字与背景短暂不同步。
- 文档 PDF 截图区域固定浅色样式，避免深色界面导致白底导出文字变淡。图片透明度和 JPEG 白底规则沿用现有行为。
- 使用指南与 README 说明自动主题行为。

## 验证

- 29 项单元测试通过。
- 4 项 Chrome 主题专项通过：三页在禁用 JavaScript 时仍实时切换且可见文本对比度至少 4.5:1；主题切换保留文件、选项、焦点、队列记录和结果；390 像素手机宽度下五个转换面板无横向溢出；深浅主题生成的 Markdown PDF 重新渲染后逐图一致，白底且存在可读文字。
- 主题专项同时实际解码 JPEG，验证透明输入仍输出白底。
- 20 项依赖文件与许可证校验、34 个发布资源构建、离线资源 SHA-256 / 版本及 PWA 范围检查通过；应用脚本语法检查通过。
- 77 项 Chrome 全量回归通过，覆盖既有转换、批量、队列、取消、压力和离线功能，以及新增主题专项。
