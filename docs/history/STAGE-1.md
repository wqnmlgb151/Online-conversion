## 证据范围

测试使用 Windows 上的 Chrome 和合成样本，不能代表所有编码、复杂 Office 排版、大文件、其他浏览器或移动设备。音视频样本只有一秒；核心下载使用经过校验的本地缓存响应相同 CDN URL，验证真实 WASM 编解码流程，不代表线上 CDN 的实时连通性。文档 PDF 仍是图片分页，Office 图片和复杂排版仍会省略。

## 部署调整

Cloudflare Pages 正式部署建议使用构建命令 `npm run build`、输出目录 `dist`、根目录留空。原来的 `exit 0` / `.` 设置需要更新。当前尚未替用户修改 Cloudflare 配置或发布。
